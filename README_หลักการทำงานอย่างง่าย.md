# SpeakUp (Promjum) — หลักการทำงานของเว็บไซต์อย่างง่าย

เว็บไซต์สำหรับฝึกพูดภาษาอังกฤษสำหรับเด็กและวัยรุ่น มี 3 ฟีเจอร์หลัก:

## 1. ระบบสมาชิก (Auth)
- สมัครสมาชิก → ยืนยันอีเมล → เข้าสู่ระบบ (username + password)
- Login ครั้งเดียวแล้ว session คงอยู่แม้ refresh หน้า (ใช้ cookie + token)
- รองรับ Google Login (ต้องตั้งค่า credentials จริงก่อนถึงจะใช้ได้)
- 1 account ต้องนั่งอยู่ที่เครื่องเดียว (ถ้า login ที่อื่น ที่เดิมจะถูกไล่ออก)

## 2. ฝึกพูด (Practice)
- เลือกหมวดหมู่ (Daily Life / Travel / Food & Dining)
- แต่ละหมวดมีประโยคให้ฝึกพูดตามลำดับ พร้อมรูปภาพและเสียงตัวอย่าง
- มี quiz คำตอบหลายตัวเลือกให้ทำหลังฟัง (บางประโยคมี บางประโยคไม่มี)
- ทำครบทุกประโยคแล้วสรุปผล session นั้น

## 3. มินิเกม (Game) — จับคู่กับเพื่อนคุยด้วยเสียงจริง
- กด "หาคู่" → ระบบจับคู่กับคนที่กดรออยู่อีกคนโดยอัตโนมัติ
- เชื่อมเสียง (voice call) ระหว่างกันแบบเรียลไทม์ผ่าน WebRTC
- เกมมี 4 รอบ สลับบทบาทกัน: คนอธิบาย (เห็นภาพเป้าหมาย ต้องพูดอธิบายเป็นภาษาอังกฤษ) ↔ คนทาย (เห็น 4 ภาพ ต้องเลือกภาพที่เพื่อนอธิบาย)
- ตอบถูกและตอบเร็ว = คะแนนสูง (คะแนนเต็มรอบละ 100 ทีมละ 400)
- เล่นจบเข้าหน้าสรุปคะแนน และ **ยังคุยกันต่อได้** จนกว่าฝ่ายใดฝ่ายหนึ่งจะกด "เสร็จสิ้น" หรือครบ 30 วินาที
- กดออกจากสายไม่ว่าทางไหน (กลับหน้าหลัก / ไปฝึกพูด / เล่นอีกรอบ / ออกจากระบบ) = ตัดสายทั้งสองฝั่งทันที โดยอีกฝ่ายจะถูกพากลับหน้าหลัก

## สถานะการ deploy
- **Backend** (NestJS): Railway — `https://promjumprojectprototype1-production.up.railway.app`
- **Frontend** (Next.js): Vercel
- **Database**: Neon Postgres (มีข้อมูล seed: หมวดหมู่, ประโยค, quiz, ชุดภาพเกม)
