ตอนนี้ระบบเสียงใช้งานได้ก็จริงแต่ก็มีปัญหาโดยเฉพาะครั้งแรก โดยการเชื่อมต่อมันยังช้าหรืออาจไม่เชื่อมต่อเลยผมไม่แน่ใจ แต่จากที่ทดลองดูการเชื่อมต่อครั้งแรกจะใช้ไม่ได้เสมอต้องกดจับคู่อีกรอบการเชื่อมต่อเสียงถึงจะสำเร็จ อยากให้ช่วยเช็คและแก้ไขให้หน่อยหากเจอปัญหา และตอนนี้ต้องการเพิ่มระบบสำหรับตรวจเช็คอยู่สองอย่าง
 
1.ระบบการ login ซ้ำกันด้วย username password เดียวกัน โดยตรวจเช็คหากมีการ login ซ้อนให้บังคับ device ที่ login ก่อนหน้า logout ออกไปและมีการแจ่้งเตือนการ login ซ้อนด้วย โดยมีการแจ้งเตือนสำหรับทั้งสองฝ่ายให้รับรู้ถึงการ login ซ้อนแต่ device ที่ login ซ้อนมาอนุญาตให้เข้าใช้ได้ปกติ และหากมีการ login ซ้อนกลับมาก็ให้ทำแบบเดียวกัน เพื่อเป็นการใช้ id เดียวกันระหว่าง website

2.ระบบตรวจเช็คการกดออกระหว่างการเล่นเกม โดยที่หน้า website ระหว่างเล่่นเกมมันมีปุ่ม กากบาท อยู่โดยหากกดแล้วเลือก ออกจากการเล่น มันจะออกไปยังหน้าหลักโดยยังทิ้งอีกฝ่ายให้เล่นอยู่ จึงต้องการแก้ไขให้มีการตรวจเช็คการกดออกระหว่างเล่นเกมโดยหากเกิดการกดออกให้แจ้งเตือนอีกฝ่ายว่ามีการกดออกสัก 1-2 วินาทีก่อน redirect user กลับไปยังหน้า homepage ให้เรียบร้อย
